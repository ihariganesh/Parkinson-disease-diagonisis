# Code of Conduct

We are building a clinically inspired, open-source project. We want this space to be welcoming, respectful, and safe for developers, clinicians, and patients.

## Standards

- Be respectful and inclusive of people from all backgrounds and experience levels.
- Assume good intent and give constructive, actionable feedback.
- Focus on technical issues, not people.
- Avoid harassment, personal attacks, or discriminatory language.
- Keep discussions professional, especially around health-related topics.

## Unacceptable Behaviour

Examples include:
- Harassment, bullying, or personal insults.
- Discriminatory jokes or language related to gender, race, religion, disability, or other protected characteristics.
- Posting others’ private information without consent.
- Repeated disruptive or bad‑faith behaviour.

## Scope

This code of conduct applies to:
- The GitHub repository (issues, discussions, pull requests).
- Community spaces such as chats or forums linked from this project.

## Reporting

If you experience or witness unacceptable behaviour:
- Report it privately via the repository’s **Security** tab or by opening a confidential issue if appropriate.
- You can also contact the maintainer via their GitHub profile: @ihariganesh.

The maintainer may take any action they deem appropriate, including warnings or restricting participation.

## Acknowledgement

This code of conduct is inspired by common open-source community guidelines and adapted for this project’s clinical context.
